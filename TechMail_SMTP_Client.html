Gmail App Password Setup

1. Enable 2-Factor Authentication on your Google account.
2. Go to myaccount.google.com/apppasswords
3. Generate a new App Password (16 characters).
4. Paste it into the Password field in SMTP Config above — not your real login password.

❓ Help & Documentation

How to Send an Email

  • 1Open SMTP Server Configuration and enter your host, port, username, and password.
  • 2Click "Test SMTP" to verify the connection.
  • 3Fill in To, Subject, and Message Body fields.
  • 4Optionally choose a template as a starting point.
  • 5Click "Send Email" — watch the progress bar complete.
  • 6The email appears in Sent. Click it to read the full message.

Reading Messages & Drafts

  • →Go to Sent or Drafts from the sidebar.
  • →Click any item in the list — the full message opens on the right panel.
  • →Use Reply or Forward to pre-fill the composer with the message details.
  • →Use Edit Draft to load a draft back into the composer for editing.
  • →Use Delete to remove the message from the list.

Security Notes

  • !Always use STARTTLS (port 587) or SSL (port 465) in production.
  • !For Gmail: use a 16-char App Password, not your real login password.
  • !Keep credentials in .env files on the server — never in source code.
  • !The PHP Mailer.php class uses TLS 1.2 minimum with peer verification.
